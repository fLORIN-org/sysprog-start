# BackupSystem — система резервного копирования

Учебный проект на Python: резервное копирование папки с хранением версий,
проверкой целостности через SHA-256 и восстановлением на выбранную дату.

## Технологии
- Python 3.14 (подходит и 3.12), только стандартные библиотеки: `hashlib`, `shutil`, `json`, `pathlib`, `datetime`
- Windows 11, PowerShell

## Структура проекта
```text
BackupSystem/
├── main.py        команды программы
├── backup.py      создание копий
├── restore.py     выбор копии по дате и восстановление
├── integrity.py   SHA-256 и manifest.json
├── storage.py     пути, имена, поиск копий
├── test_data/documents/   тестовые документы
├── backups/       резервные копии
└── restored/      сюда восстанавливаем
```

## Команды
```powershell
python main.py check                       # проверить структуру проекта
python main.py backup                      # создать копию
python main.py list                        # список копий
python main.py verify                      # проверить SHA-256 всех копий
python main.py restore backup_2026-11-16_14-01-47   # восстановить по имени
python main.py restore "2026-11-16 14:01"            # восстановить по дате
python main.py compare папка1 папка2       # сравнить две папки по SHA-256
```

## Как это работает
1. **Копия.** Программа считает SHA-256 исходных файлов, копирует их во временную
   папку `.tmp_backup_...`, сверяет хеши и записывает `manifest.json`
   (дата, размеры, хеши). Только после этого папка переименовывается в
   `backup_ГГГГ-ММ-ДД_ЧЧ-ММ-СС`.
2. **Защита от сбоев.** При ошибке или прерывании настоящая копия не появляется,
   программа пишет `[ОШИБКА]`, а не успех. Недокопированная папка `.tmp_...`
   помечается как «неполная».
3. **Версии.** Каждая копия хранится в своей папке, старые никогда не перезаписываются.
4. **Восстановление.** Перед восстановлением копия проверяется по SHA-256.
   Повреждённая копия не восстанавливается. Файлы пишутся в `restored/`,
   а не поверх исходных документов. Существующая папка не перезаписывается.
5. **Выбор по дате.** Берётся самая свежая копия, созданная не позже указанного момента.

## Проведённые испытания
| Испытание | Результат |
|---|---|
| Первая копия | создана, SHA-256 проверен |
| Изменение и удаление документов, вторая копия | 3 версии хранятся одновременно |
| Восстановление первой версии | вернулись удалённые файлы |
| Сравнение SHA-256 исходных и восстановленных файлов | совпали |
| Порча файла в копии (размер и один бит) | `verify` нашёл оба случая |
| Имитация сбоя при копировании | копия не создана, успех не заявлен |
| Восстановление из повреждённой копии | отказ, в `restored` ничего не появилось |
| Повторные запуски | предыдущие копии сохранены |

## Ограничения
- Каждая копия хранит папку целиком, а не только изменённые файлы (нет экономии места).
- Копируется только папка `test_data/documents`.
- Права доступа и метаданные файлов не сохраняются.
