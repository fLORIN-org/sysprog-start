# ЛР 5. Рождение процесса

**Система:** Windows 11 Pro 25H2 (сборка 26200.9711), x64, AMD

**Программа записи:** Process Monitor (Sysinternals)

## Рождение

**Родитель (имя и номер):** cmd.exe, PID 3104

**Номер нового процесса:** 14188 (HOSTNAME.EXE)

**Событие или вызов, которым создан процесс:** Process Create, результат SUCCESS. У нового процесса событие Process Start, Parent PID 3104.

**Библиотек загружено и первая из них:** около 19 библиотек, первая — ntdll.dll.

## Завершение

**Код завершения у ребёнка и у родителя:** 7 у дочернего процесса и code 7 у родительского cmd.exe.

**Программа nosuch:** проверено 27 папок, ошибка NO SUCH FILE, код завершения 9009.

## Запуск из Python

**Номер Python и номер ребёнка:** python.exe PID 21588, дочерний hostname.exe PID 9764. Перед ним также наблюдался процесс python.exe PID 21648.

**Чем запуск из Python отличается от запуска из оболочки:** при запуске из оболочки cmd.exe непосредственно создаёт новый процесс. При запуске из Python программа создаётся через subprocess, поэтому родителем hostname.exe становится процесс python.exe.

**Не получилось:** существенных проблем при выполнении лабораторной работы не возникло.
