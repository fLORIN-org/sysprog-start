# ЛР 6. Кто загружает процессор

**Система:** Windows 11  
**Ядер (логических процессоров):** 16

## Одна нагрузка

Процент процесса в мониторе: 6,2%  
Общая загрузка: 9%  
На каких ядрах видна нагрузка: нагрузка распределяется планировщиком Windows между логическими процессорами.

## Две нагрузки

Проценты обеих нагрузок и общая загрузка: первый Python — 6,2%, второй Python — 6,2%, общая загрузка — 15%.

На одном ядре: оба процесса ограничены логическим процессором ЦП 0.

## Процессорное время

Первый замер: 0,0 сек  
Второй замер: 0,0 сек  
Пауза: 3 секунды.

Загрузка по замерам: процессорное время практически не увеличилось, так как программа большую часть времени ожидала с помощью time.sleep().

Почему процент в мониторе не говорит о скорости работы: процент показывает долю используемого процессорного времени, но не количество выполненной работы. На скорость также влияют частота процессора, количество ядер и другие процессы.

Не получилось: существенных проблем при выполнении лабораторной работы не возникло.
