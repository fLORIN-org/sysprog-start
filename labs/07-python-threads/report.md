# ЛР 7. Потоки Python и GIL

**Система:** Windows 11 Pro 25H2, x64  
**Процессор:** AMD Ryzen 7 7800X3D  
**Количество логических процессоров:** 16  
**Версии Python:** 3.14.7 (обычная версия с GIL), 3.14.10 (free-threaded, без GIL).

## Python с GIL

**Количество потоков в программе:** 4 рабочих потока.

При включённом GIL одновременно выполняется только один поток Python-кода. Остальные потоки ожидают возможности получить GIL.

**Загрузка процессора:** указать значение по скриншоту 01_gil_monitor.png.

**Количество одновременно выполняющихся потоков Python:** 1.

## Потоки процесса

В программе создаются четыре рабочих потока. Во время выполнения часть потоков может ожидать получения GIL, а один поток выполняет вычисления.

Список потоков процесса показан на скриншоте 02_threads.png.

## Python без GIL

Использовалась версия Python 3.14.10 free-threaded.

Без GIL несколько потоков могут одновременно выполнять вычисления на разных ядрах процессора.

**Загрузка процессора:** указать значение по скриншоту 03_nogil_monitor.png.

**Количество одновременно выполняющихся рабочих потоков:** до 4.

## Время выполнения

| Режим | 1 поток | 2 потока | 4 потока |
|---|---:|---:|---:|
| Python с GIL | 3,50 с | 4,68 с | 4,51 с |
| Python без GIL | 3,79 с | 2,88 с | 1,47 с |
| Python без GIL, но с PYTHON_GIL=1 | 3,69 с | 5,08 с | 4,78 с |

В режиме без GIL четыре потока выполнили вычисления примерно в 3,2 раза быстрее, чем четыре потока в обычном Python с GIL.

## Ожидающие потоки

| Количество потоков | Время выполнения |
|---|---:|
| 1 поток | 2,00 с |
| 4 потока | 2,00 с |

Ожидающие потоки ускоряются даже при включённом GIL, потому что функция time.sleep() освобождает GIL на время ожидания. Поэтому несколько потоков могут ожидать одновременно.

## Вывод

В ходе лабораторной работы было изучено влияние GIL на многопоточность Python.

При включённом GIL несколько потоков не могут одновременно выполнять Python-код, поэтому увеличение количества потоков не ускоряет вычисления.

В версии Python без GIL потоки могут работать параллельно. В проведённом эксперименте четыре потока выполнили задачу за 1,47 секунды вместо 4,51 секунды.

Также было проверено ожидание потоков с помощью time.sleep(). Четыре потока завершили ожидание примерно за то же время, что и один поток.

## Трудности

При установке Python без GIL потребовалась дополнительная установка uv. Исполняемый файл Python без GIL запускался по полному пути, так как его папка не была добавлена в PATH.
